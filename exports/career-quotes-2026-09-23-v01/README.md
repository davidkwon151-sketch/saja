# 커리어 나침반 명언 자료 v01

2026-09-23에 취업·이직을 준비하는 사람을 위해 짧은 문구 6개를 골랐습니다.

- `quotes.json`: 앱에서 읽기 쉬운 목록. 기존 `CareerQuote`의 `text`, `attribution`, `sourceUrl` 필드와 호환됩니다.
- `quotes.csv`: 엑셀 등에서 검토할 목록. UTF-8 BOM 형식입니다.
- `cards/*.svg`: 프로젝트 색상을 사용해 새로 만든 1080×1080 벡터 이미지 6개. 확대해도 화질이 유지됩니다.
- 이 폴더와 같은 이름의 `.zip`: 위 파일을 한 번에 내려받는 압축 파일.

`display_ko`는 명언의 직역이 아니라 이 프로젝트를 위해 새로 쓴 취업·이직 맥락 문장입니다. 카드와 목록에는 원문 출처를 적었습니다. 사용 전에는 `sourceUrl`을 열어 원문과 표기를 다시 확인하세요. 영어 인물 표기는 각 인용 사이트의 표기이며, 발언의 1차 기록까지 검증했다는 뜻은 아닙니다.

제시된 국내 서비스 중 명언일기는 루빗 앱의 기능으로 확인됐고, 글과길은 요청한 명언 서비스로 확인되지 않았습니다. 네이버 지식백과 원문에는 접근하지 못해 문구를 추출하지 않았습니다. 이 세 곳의 문구나 이미지는 이 묶음에 포함하지 않습니다. 한국어 문구는 기존 프로젝트에서 사용 중인 한국 속담 자료를 활용했습니다.

원본 사이트의 사진·카드 이미지는 사용 허락을 확인하지 못해 포함하지 않았습니다. SVG 이미지는 새로 제작했지만, 그 안의 인용문을 공개 서비스에서 쓰는 경우 해당 문구의 권리와 인물 표기를 별도로 검토해야 합니다. 원문 출처 링크를 화면에도 함께 표시하세요.

앱에 적용할 때는 `quotes.json`과 필요한 `cards/*.svg`를 프로젝트의 `public` 또는 데이터 위치에 복사하고, 각 항목의 `image`와 `sourceUrl`을 연결하면 됩니다. 현재 앱 동작과 기존 격언 목록은 변경하지 않았습니다.
