# 📋 기획서 (PRD): 취업·이직 사주 행동 계획 서비스

> PRD는 무엇을 왜 만들고, 어떤 결과가 나오면 완성인지 정리한 기획서입니다.

작성일: 2026-09-23

기반: `saju-starter-code`의 기존 사주 계산 화면

상태: 사용자와 첫 범위를 구체화함. 구현 전 기획서

## 1. 풀고자 하는 문제

- **지금은 이렇게 해요:** 현재 사용자가 고민을 해결하려고 어떤 방법을 쓰는지는 확인하지 않았습니다.
- **이게 불편해요:** 삶의 문제에 답답함을 느끼며, 특히 취업·이직에서 지금 무엇을 해야 할지 구체적인 방향을 얻기 어렵습니다.
- **이렇게 되면 좋겠어요:** 자신의 고민을 먼저 적고 사주를 참고한 해석과 함께, 목표 입사일까지 실행할 수 있는 단계별 행동 계획과 현재 모집 중인 기회를 한곳에서 봅니다.

## 2. 사용자와 가장 중요한 경험

- **누가:** 취준생, 이직 준비자 등 일반인. 첫 범위는 취업·이직 고민에 집중합니다.
- **언제:** 취업·이직 방향이 막막하거나 입사 목표일에 맞춰 준비 계획을 세우고 싶을 때.
- **어디서:** 브라우저에서 이용하는 웹 서비스. 기기별 우선순위는 미정입니다.
- **가장 중요한 경험:** 고민을 먼저 적으면, 추상적인 운세보다 **입사 목표일에 맞춘 실질적인 행동 계획**을 순서대로 받습니다.

## 3. 입력 자료

**필수 입력**

1. 현재 취업·이직 고민을 설명하는 글
2. 생년월일 — 출생시간은 입력받지 않음
3. 입사 목표일
4. 희망 직무
5. 현재 상태 — 예: 취준생, 재직 중 이직 준비

- **추가 정보:** 희망 근무 지역, 경력·경험, 관심 활동을 입력받을지는 구현 전에 결정합니다. 정보가 없으면 공고의 적합성을 단정하지 않습니다.
- **개인정보:** 생년월일과 고민 글에는 개인 정보나 민감한 사연이 포함될 수 있습니다. 저장·보관 여부와 기간은 미정이며, 별도 결정 전에는 저장 기능을 범위에 넣지 않습니다.
- **필요한 외부 자료:** 현재 모집 중인 채용공고, 교육, 인턴, 공모전, 해커톤, 데이터톤 등의 원문 모집 페이지. 특정 제공처나 연동 방식은 미정입니다.

## 4. 핵심 기능: 첫 버전에서 할 일

1. 사용자가 **고민을 먼저** 적고, 생년월일·입사 목표일·희망 직무·현재 상태를 입력합니다. 출생시간 입력은 제거합니다.
2. 기존 사주 계산 기능을 바탕으로 고민에 관련된 해석을 보여줍니다. 출생시간이 없어서 알 수 없는 내용은 확정적으로 말하지 않습니다.
3. AI가 희망 직무, 현재 상태, 남은 기간, 고민 내용을 고려해 **입사 목표일까지의 단계별 행동 계획**을 작성합니다. 교육, 포트폴리오, 인턴, 채용 지원, 공모전, 해커톤, 데이터톤 등 관련 활동을 필요에 따라 제안합니다.
4. 계획에 연결할 **현재 모집 중인 실제 기회**를 찾아 이름, 원문 링크, 확인 시점, 확인 가능한 모집 마감일·지원 자격을 표시합니다. 확인하지 못한 내용은 추측으로 채우지 않습니다.
5. 지원 조건이 맞지 않거나 확인 가능한 모집 공고가 없으면 그 사실을 명확히 알리고, 공고 없이도 시작할 수 있는 다음 행동을 제안합니다.

- **AI에게 맡길 것:** 고민을 이해하기 쉬운 말로 정리하고, 개인 상황과 목표일까지의 일정에 맞춰 행동 계획 초안을 작성합니다.
- **사용자가 확인할 것:** 제안이 자신의 실제 경험과 여건에 맞는지, 공고 원문에서 모집 상태·자격·마감일이 맞는지 확인하고 지원 여부를 결정합니다. 사주 해석이나 AI 계획은 입사 결과를 보장하지 않습니다.

## 5. 결과와 완료 조건

- **결과물:** 웹 화면에 고민과 관련된 사주 해석, 날짜 또는 단계별 행동 계획, 관련 실제 모집 기회 목록을 보여줍니다.
- **정상 입력:** 취준생이 입사 목표일·희망 직무와 고민을 입력하면, 목표일까지 남은 기간에 맞춘 순서 있는 할 일과 확인 가능한 실제 기회가 나타납니다.
- **빈 값·잘못된 값:** 필수 입력이 없거나 입사 목표일이 지난 날짜이면, 해당 항목을 알려주고 수정할 수 있어야 합니다.
- **외부 정보 확인 실패:** 공고를 확인할 수 없으면 실제 모집 중이라고 표시하지 않고, 확인 실패를 알립니다. 만들어낸 이름·링크·마감일을 보여주지 않습니다.
- **검증 기준:** 출생시간 없이 정상 흐름이 완료되고, 공고는 원문 링크와 확인 시점이 있으며, 행동 계획 각 단계에 사용자가 직접 할 일이 적혀 있어야 합니다.

## 6. 이번 범위에서 제외할 것

- 결제
- 상담사 연결
- 취업·이직 외의 고민별 맞춤 행동 계획은 첫 버전 이후에 확장할 후보입니다. 서비스의 장기 대상은 일반인 전체입니다.
- 회원가입, 결과 저장, 알림, 다른 사람과 공유는 아직 결정하지 않았습니다. 이번 기획서에서는 필수 기능으로 확정하지 않습니다.

## 8. 이번 작업에서 완성을 목표로 할 것

이번 단계는 **기획서 작성까지**입니다. 코드는 수정하지 않습니다. 구현 단계에서는 먼저 고민 입력 → 생년월일 등 필수 정보 입력 → 사주 해석과 행동 계획 → 실제 모집 기회 확인까지 한 흐름을 검증합니다.

실습 종료 시각과 남은 시간은 확인하지 않았습니다. 구현 일정은 시작할 때 다시 잡습니다.

## 9. 첫 구현 목표 (30분 예산)

고민을 첫 입력으로 받는 화면을 만들고, 출생시간 없이 생년월일·입사 목표일·희망 직무·현재 상태를 입력받아 결과 화면까지 이어지는 가장 작은 흐름을 확인합니다. 실제 공고 검색과 AI 계획 생성의 연결 순서는 구현 착수 시 외부 자료 접근 방법을 확인한 뒤 정합니다. **현재는 구현하지 않습니다.**

## 11. 2026-09-23 추가 범위: 로그인과 해석 저장

참가자가 시제품을 본 뒤 Google 로그인과 사주 해석 결과 저장을 요청했다. 위 3·6·8·9절의 “저장 미정/제외”는 최초 범위의 기록이며, 이번 추가 범위에는 적용하지 않는다. 로그인 전에도 해석은 사용 가능하다. 로그인한 사용자의 새 해석 결과 중 요약·강점·점검할 점·질문만 Supabase에 자동 저장하고 최근 10개를 다시 보여준다. 생년월일과 고민 원문은 저장하지 않는다. 저장 실패는 해석 결과 표시를 막지 않는다. 자세한 동작은 `docs/specs/003-google-sign-in.md`와 `004-save-saju-reading.md`를 따른다.

## 12. 2026-09-23 추가 변경: 모집 목록 제거와 현대적 해석

참가자가 실제 공고 목록이 충분하지 않아 `LIVE OPPORTUNITIES`를 제거하도록 요청했다. 위 1·3·4·5·8·10절에 적힌 공고 목록 제공 목표는 이전 범위의 기록으로 남기고, 현재 결과 화면과 서버에서는 공고 조회를 제외한다. 사주 해석은 한자와 낡은 표현을 걷어내고, 취업·이직에 활용할 잠재력·구체적 행동·짧은 격언을 담은 현대적인 문장으로 제공한다. 저장된 과거 해석도 화면에는 한자 없이 표시한다. 자세한 동작은 `docs/specs/005-modern-career-reading.md`를 따른다.

## 13. 2026-09-23 추가 변경: 개인화된 미래 장면

참가자가 제공한 이미지의 낙관적인 장면을 결과 마지막에 배치한다. 이미지 위 인물의 나이는 사용자의 만 나이 ±7살 안에서 동적으로 표시한다. `내 고민과 연결한 격언`도 나이와 취업·이직 고민에 맞춰 마지막에 보여준다. 메시지는 인생과 커리어가 정해진 운명이 아니라 현재의 선택과 행동으로 만들어진다는 점이다. 자세한 동작은 `docs/specs/006-personal-future-ending.md`를 따른다.

## 14. 2026-09-23 추가 변경: 언어, 안내자 디자인, 격언 출처

참가자가 세 서브에이전트로 화면 문구의 현대화와 한국어·영어 선택, 쿼카 안내자 디자인, 국내외 출처를 확인한 고민별 격언 수집을 요청했다. 새 분석은 선택 언어로 제공하고 저장된 과거 글의 언어는 유지한다. 쿼카 이미지는 독창적으로 만들고, 명언·격언은 짧은 전통 속담 중심으로 출처를 남긴다. 자세한 기준은 `docs/specs/007-career-copy-localization.md`부터 `009-sourced-career-quotes.md`까지 따른다.

## 15. 2026-09-23 추가 변경: 마지막 장면의 문구

미래 장면의 네 나이표에는 설명 문구를 빼고 나이 숫자만 표시한다. 고민에 맞는 격언은 한국어 화면에서도 영문 문장 한 개를 보여주며, 아래의 개인별 실천 문장은 선택한 화면 언어로 표시한다.

## 16. 2026-09-23 추가 변경: 반응형 쿼카 안내자

참가자가 제공한 로컬 쿼카 페이지의 두 이미지와 반응 동작을 커리어 나침반 첫 화면에 적용한다. 쿼카는 천천히 움직이고, 마우스·펜 접근이나 클릭·터치·키보드 조작에 웃음으로 답한다. 한국어·영어 문구, 움직임 줄이기 설정, 모바일 화면을 지원한다. 자세한 기준은 `docs/specs/010-responsive-quokka-animation.md`를 따른다.
