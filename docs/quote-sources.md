# 커리어 격언 출처

2026-09-23에 공개 웹 페이지를 읽어 취업·이직 상황에 연결 가능한 짧은 전통 속담과 명언을 골랐습니다. 대량 복사나 주기적 수집 프로그램은 사용하지 않습니다.

국내·해외 자료를 함께 조사했으며, 현재 화면에는 이용자 요청에 따라 영문 명언 한 개와 영문 격언 한 개를 함께 표시합니다. 한국어 화면에는 고민과 연결한 실천 문장을 한국어로 표시합니다.

모두 특정 개인의 발언으로 표시하지 않습니다. 위키인용집 페이지의 편집·배열은 [CC BY-SA 조건](https://en.wikiquote.org/wiki/Wikiquote:Copyrights)을 따르며, 실제 화면에는 짧은 문구와 출처 링크를 함께 표시해야 합니다. 이 파일은 법률 판단이나 모든 개별 문구의 저작권 상태에 대한 보증은 아닙니다. 문구를 길게 확대 인용하거나 출처 없는 유명인 이름을 붙이지 않습니다.

고민을 분류하기 어려울 때도 출처를 확인한 기본 명언과 격언을 표시합니다.
