# 014 · 레이아웃과 톤 앤 매너 개선

## 목적

입력 양식처럼 보이던 화면을 믿을 수 있고 따뜻하며 정돈된 커리어 "나침반"처럼 느껴지게 한다. 쿼카 안내자와 기존 색 방향(크림 배경, 진한 청록, 코럴 강조)은 유지하고 위계, 글자, 간격, 결과 가독성, 모바일 흐름을 다듬는다.

## 동작

1. **디자인 토큰**: `app/globals.css`의 `:root`에 글꼴·글자 크기·간격·모서리·그림자·보조 색 토큰을 추가한다. 기존 변수 이름(`--ink`, `--muted`, `--blue`, `--border`, `--paper`, `--white`, `--focus`, `--error`, `--coral`, `--mint`)과 TSX에서 쓰는 클래스 이름은 그대로 유지한다. 다른 화면 CSS(`quotes.css`, `compass.css`)도 새 토큰을 쓸 수 있다.
2. **한글 가독성**: 본문에 `word-break: keep-all`을 적용해 단어 중간 줄바꿈을 막고, 제목은 `text-wrap: balance`, 문단은 `pretty`로 정리한다. Windows용 `Malgun Gothic`을 글꼴 목록에 넣고, 설치된 경우에만 Pretendard를 쓴다(외부 CDN·새 패키지 없음).
3. **첫 화면**: 눈썹 문구를 작은 칩으로, 브랜드 앞에 나침반 모양 표식을 둔다. 소개 아래에 "지금 고민 적어보기" 이동 버튼과 "로그인 없이 · 약 1분 · 출생시간 불필요" 안내, 결과와 이어지는 3단계 진행 순서를 보여준다. 쿼카 뒤에는 은은한 원형 배경을 둔다.
4. **입력 카드**: 입력 테두리를 흰 배경 대비 3:1 이상(`--line-strong`)으로 높이고 마우스·초점 상태를 추가한다. 개인정보 안내는 정보 아이콘과 구분선으로 제출 버튼과 분리하고, 제출 버튼에 방향 화살표를 둔다.
5. **결과 가독성**: 인사이트 요약은 한 줄 길이를 제한하고, 강점·체크포인트를 색이 다른 두 패널로 나눈다. 3단계 계획은 번호 원과 점선 연결선이 있는 타임라인으로 보여주고, 기간은 작은 칩으로 표시한다. 진행 중에는 회전 표시, 오류는 옅은 붉은 상자로 보여준다.
6. **구역 리듬**: 결과·미래 장면·꼬리말 사이 간격을 `--space-section`으로 통일하고, 구역 눈썹 문구 앞에 코럴 선을 둔다. 꼬리말에 브랜드 이름을 더한다.
7. **모바일(≤720px)**: 첫 화면 쿼카를 최대 260px로 줄여 입력 영역까지의 스크롤을 줄이고, 이동 버튼을 전체 너비로 둔다. 계획 연결선은 숨기고 카드 안쪽 여백을 줄인다.
8. **메타데이터**: `viewport`의 `themeColor`·`colorScheme`, `openGraph` 기본값을 추가한다.
9. 쿼카 애니메이션, 움직임 줄이기, 초점 표시, 44px 이상 누름 영역은 유지한다. 움직임 줄이기에서는 회전 표시와 버튼 들림도 멈춘다.

## 범위 밖

- `app/i18n.ts`, `app/saju-form.tsx` 등 다른 담당 파일의 문구·마크업 변경은 제안만 남긴다. 첫 화면 새 문구는 `app/page.tsx`의 `heroCopy`에 두었고, i18n으로 옮길 수 있도록 키 이름을 맞췄다.
- 다크 모드, 새 글꼴 패키지, 대규모 구조 변경.

## 완료 조건

- `npm run check`, `npm run build`가 통과한다.
- 데스크톱과 375px 화면에서 첫 화면·입력·결과를 가로 넘침 없이 읽고 조작할 수 있다.
- 쿼카의 대기·웃음 동작과 언어 전환이 유지된다.

## 검증 결과 · 2026-09-25

- **이전 상태(배포 사이트, 375px)**: 첫 화면 소개 문장이 단어 중간에서 줄바꿈됨("찾 / 아보세요", "움직 / 일"). 입력 테두리 `#b8cec3`은 배경 대비 약 1.6:1로 WCAG 1.4.11(3:1) 미달. 입력 카드 시작 위치 919px, 이동 수단 없음.
- **변경 후(로컬 `next dev`, 헤드리스 Chrome 1280×800·375×812, 기본 계획 결과까지 제출)**: 가로 넘침 없음(`scrollWidth` = 화면 너비, 넘치는 요소 0개). 한글 단어 중간 줄바꿈 사라짐. 결과의 강점·체크포인트 패널, 번호 원·연결선 타임라인, 기간 칩, 코럴 선 눈썹 문구를 확인함. 영어 화면(375px)도 가로 넘침 없음.
- 모바일 입력 카드 시작 위치는 1057px로 이전보다 약 140px 아래임. 대신 첫 화면에 "지금 고민 적어보기" 이동 버튼이 첫 화면 안에 보임. 쿼카는 300px → 260px로 줄임.
- 44px 미만 누름 영역 중 이 Spec의 요소는 없음. 측정된 22px 입력(체크박스류)과 23px 출처 링크는 다른 담당 파일의 요소임(출처 링크는 문장 속 링크 예외).
- `tests/quokka-animation.test.ts`: 모바일 쿼카 폭 검사를 `min(100%, 370px)` 고정값에서 240–379px 범위로 완화함. 의도적으로 폭을 줄였기 때문임. 5개 모두 통과.
- `npm run build`: 성공(Compiled successfully, TypeScript 통과, 정적 페이지 5/5).
- `npm run check`: 타입 검사 통과, 테스트 84개 중 82개 통과. 실패한 2개(`auth-storage`, `date-input`)는 `app/future-ending.tsx`의 `import "./quotes.css"`를 tsx 테스트 실행기가 불러오지 못해 생긴 SyntaxError임. 이 Spec의 변경과는 관계없음. 해결 방법: 컴포넌트 안의 CSS import(`quotes.css`, `compass.css`)를 `app/layout.tsx`로 옮김.
- 쿼카 대기·웃음 동작은 코드와 CSS를 바꾸지 않았고 테스트로 확인함. 실제 기기의 움직임 줄이기 전환은 실행하지 않음.
- 전체 테스트가 통과하지 않았으므로 `docs/status.md`에는 아직 체크하지 않음.
