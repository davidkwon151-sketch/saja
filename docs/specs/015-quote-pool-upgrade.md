# 015 · 명언·격언 풀 확장과 고민 맞춤 선택

## 목적

결과 마지막 장면의 명언·격언이 늘 같은 몇 문장(예: 서로 다른 고민에 모두 "Well done is better than well said.")으로 반복되던 문제를 없앤다. 009·011의 원칙(영어 원문 표시, 출처 링크, 짧은 발췌, 검증되지 않은 문장을 유명인에게 붙이지 않음)은 그대로 지킨다.

## 동작

1. 출처 페이지에서 원문을 자동으로 확인한 명언 40개 이상, 세계 각지 격언 30개 이상을 쓴다. 확인 스크립트는 페이지를 `<h2>`(하위 `<h3>`/`<h4>` 포함) 구역으로 나누고, 처음 일치한 곳이 Disputed·Misattributed·Quotes about…·About…·See also·Attributed·Unsourced 구역이면 제외한다. 결과는 `exports/quote-verification-2026-09-25.txt`에 남긴다.
2. 각 문장은 id, 종류(명언/격언), 영어 원문, 한국어 번역, 출처 표기, https 출처 링크, 주제 태그(start, setback, skill, change, together, gap, patience, direction, courage, balance)를 가진다.
3. 고민 문장(한국어·영어 키워드), 현재 상태(취업 준비 중 / 재직 중 이직 준비 / 재취업 준비 중), 직무, 나이를 태그별 가중치로 바꾸고, 점수가 높은 후보 중에서 가중 무작위로 고른다.
4. 브라우저가 최근 본 문장 id 20개를 기억해(`career-compass-recent-quotes`) 요청에 보내면, 서버는 그 문장을 빼고 고른다. 모두 빠지면 전체에서 다시 고른다.
5. 격언 아래 연결 문장은 태그마다 한국어·영어 세 가지 이상이며, 희망 직무를 넣어 이번 주에 할 구체적 행동으로 바꾼다.
6. 한국어 화면은 영어 원문 아래 한국어 번역을 보여 주고, 영어 화면에는 한글이 나타나지 않는다. 출처는 "출처/Source" 표시와 함께 새 창 링크로 연다.

## 완료 조건

- 풀 크기·중복 없음·https 출처·번역·원문에 한글 없음·검증 로그 PASS가 테스트로 확인된다.
- 서로 다른 고민이 서로 다른 명언·격언·연결 문장을 받고, 최근 본 문장이 제외되며, random을 주입하면 결과가 재현된다.
- 영어 화면 결과와 화면에 한글이 없다.
- 기존 결과 화면 제목·레이블(내 고민과 연결한 명언/격언, A QUOTE FOR YOUR NEXT STEP, A PROVERB FOR YOUR CONCERN)이 유지된다.
