# 003 · Google 로그인

## 목적

사용자가 Google 계정으로 로그인해 자신의 사주 해석을 저장하고 다시 볼 수 있게 한다.

## 범위와 동작

1. 기존 사주 입력·해석은 로그인 없이 계속 사용할 수 있다.
2. 화면에 `Google로 로그인` 버튼과 로그인 상태를 표시한다. Supabase Auth의 Google 제공자로 이동하며, 로그인 후 현재 앱 주소로 돌아온다.
3. 로그인한 사용자는 로그아웃할 수 있다. 로그아웃하면 이 브라우저에 표시된 저장 내역을 즉시 숨긴다.
4. Supabase URL과 publishable key는 기존 `NEXT_PUBLIC_` 환경변수를 사용한다. 비밀키는 브라우저에 넣지 않는다.
5. 제공자 설정이나 인증이 실패하면 오류를 보여주고 기존 비회원 해석은 계속 사용할 수 있다.

## 이번 범위에서 제외

- 이메일·비밀번호 로그인, 다른 소셜 로그인, 계정 프로필 수정, 계정 삭제.
- 배포 주소의 허용 목록 설정. 배포 주소가 정해지면 별도로 추가한다.

## 완료 조건과 검증

- Google 제공자가 켜져 있고 로컬 앱 주소가 Supabase의 허용 복귀 주소에 포함된다.
- 버튼이 Google 인증으로 이동하고, 세션이 생기면 로그인 상태를 표시한다.
- 로그인 실패·설정 누락이 기존 해석을 막지 않는다.
- 타입 검사, 빌드, 실제 브라우저의 비회원 흐름을 확인한다. 실제 Google 계정 승인은 참가자가 수행한다.

## 검증 기록 · 2026-09-23

- Supabase Google 제공자 활성화와 `http://127.0.0.1:3000/**` 복귀 주소 등록을 확인했다.
- 실제 브라우저에서 `Google로 로그인`을 누르면 Google 계정 선택 화면까지 이동한다.
- `npm run check` 26/26 통과, `npm run build` 통과. 비회원 해석 흐름도 확인했다.
- 실제 Google 계정 선택, 앱 복귀 후 로그인 상태 표시, 로그아웃은 참가자 계정 사용 전까지 미검증이다.
