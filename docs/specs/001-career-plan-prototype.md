# 001 · 취업·이직 행동 계획 시제품

## 목적

사용자가 고민을 먼저 적고 생년월일, 입사 목표일, 희망 직무, 현재 상태를 입력하면 사주를 참고한 단계별 취업·이직 행동 계획과 실제 모집 공고를 한 화면에서 확인한다.

## 입력과 흐름

1. 고민을 첫 입력으로 보여준다. 출생시간은 묻지 않는다.
2. 양력 생년월일, 미래의 입사 목표일, 희망 직무, 현재 상태를 받는다.
3. 입력을 검사하고 날짜 기반 사주 3주(년·월·일)를 계산한다. 출생시간을 모르므로 시주는 만들거나 표시하지 않는다.
4. 남은 기간에 맞춰 단계별 행동 계획을 보여준다. API 키가 준비되면 Gemini가 맞춤 계획을 작성하고, 키가 없거나 호출에 실패하면 분명히 표시한 기본 계획을 보여준다.
5. Remotive의 공개 API에서 현재 게시 중인 해외 원격 채용 공고를 조회하고, 직무와 관련된 공고 이름·회사·원문 링크·지역 제한·조회 시점을 표시한다. 모집 마감일이 없으면 임의로 만들지 않는다.

## 완료 조건

- 고민이 결과보다 먼저 나온다.
- 출생시간 입력이 없고 결과에는 시주가 나오지 않는다.
- 단계마다 사용자가 직접 할 일과 목표일까지의 시점이 보인다.
- 공고는 실제 공개 API에서 받은 항목만 표시한다. 불러오기 실패나 일치하는 공고가 없으면 이를 알린다.
- 빈 값과 지난 입사 목표일을 거부한다.
- 결제와 상담사 연결은 없다.

## 시제품의 경계

- 국내 공고는 현재 인증키가 필요한 고용24 API와 연결하지 않는다. 이 시제품의 자동 공고 목록은 해외 원격 공고에 한정한다.
- Remotive는 모집 마감일을 제공하지 않으므로 사용자가 원문에서 지원 가능 여부를 최종 확인한다.
- API 키가 없는 실행 환경에서는 Gemini 맞춤 생성 대신 기본 계획을 표시한다. AI가 작성한 것으로 표현하지 않는다.
- 입력과 결과는 저장하지 않는다.

## 검증

- 기존 사주 계산 테스트와 새 날짜 기반 계산·입력 검사 테스트
- 타입 검사 및 빌드
- 실제 브라우저에서 정상 입력, 오류 입력, 좁은 화면, API 실패 메시지 확인

### 2026-09-23 확인 결과

- `npm run check`: 타입 검사와 테스트 20개 통과.
- `npm run build`: 성공.
- 실제 브라우저: 고민·생년월일·목표일·직무·현재 상태 입력 후 3주 사주 참고 정보, 단계별 계획, Remotive 공고 이름과 원문 링크 표시를 확인. 지난 입사 목표일에는 오류 안내를 확인.
- 폭 약 560px의 좁은 화면에서 입력과 공고 카드가 한 열로 표시되고 가로 넘침이 없음을 확인. 브라우저 오류 기록 없음.
- Gemini 인증값이 없어 AI 생성 성공 흐름은 확인하지 못함. 공고 API 실패 흐름은 코드에 안내가 있으나 실제 실패 상황은 재현하지 않음.
