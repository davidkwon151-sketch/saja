# 007 · 커리어 언어와 문구

## 목적

서비스 화면에서 낡은 명칭을 걷어내고, 한국어와 영어 사용자가 같은 입력·결과 흐름을 이용할 수 있게 한다.

## 동작

1. 제품명과 사용자에게 보이는 문구에서 `사주` 명칭을 제거하고 현대적인 커리어 안내 말투로 바꾼다. 계산 방식의 내부 파일명과 과거 기획 이력은 유지한다.
2. 화면 상단 오른쪽에 한국어/English 선택을 제공한다. 선택은 브라우저에 기억하고 새로고침 뒤에도 적용한다.
3. 입력 이름표, 버튼, 상태·오류 안내, 해석 영역, 계획 영역, 저장 내역의 UI 문구를 선택 언어로 표시한다. 새 분석 요청에는 언어를 함께 보낸다.
4. AI가 가능하면 선택 언어로 해석과 계획을 작성한다. AI 실패 시 기본 계획도 선택 언어로 표시한다. 이전에 저장한 글의 원문 언어는 유지하고 이 사실을 알린다.
5. 브라우저 탭 제목과 문서 언어도 선택에 맞춘다.

## 완료 조건

- UI에 `사주` 명칭이 보이지 않고 두 언어 선택 및 유지가 동작한다.
- 영어 입력·생성 흐름에서 새 결과와 오류 안내가 영어로 표시된다.
- 로그인·저장·비회원 사용 흐름이 유지된다.

## 검증 결과 · 2026-09-23

실제 브라우저에서 한국어·영어 전환과 새로고침 뒤 선택 유지를 확인했다. 한국어 화면의 기존 계정 기록과 별도 비회원 주소의 생성 흐름을 확인했다. 자동 검사 39개와 빌드가 통과했다.
