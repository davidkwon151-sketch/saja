# 008 · 쿼카 커리어 안내자 디자인

## 목적

텍스트 중심 화면에 친근한 쿼카 캐릭터와 일관된 색·형태·안내 톤을 적용해 긴 입력·결과 흐름을 읽기 쉽게 만든다.

## 동작

1. 쿼카 디자인 사례는 참고만 하고 타인의 캐릭터 이미지를 복제하지 않는다. 독창적인 캐릭터 자산을 프로젝트에 저장한다.
2. 첫 화면에서 쿼카를 안내자처럼 배치하고, 입력·인사이트·계획·결과까지 같은 색과 카드 형태를 이어 간다. 장식이 입력이나 결과 문구를 가리지 않는다.
3. 밝고 격려하는 색, 카드·아이콘·간격을 일관되게 적용한다. 한국어·영어 문구 길이 차이도 수용한다.
4. 375px 모바일과 데스크톱에서 읽기·클릭·키보드 탐색이 가능해야 한다. 장식 이미지는 보조기술 사용을 방해하지 않는다.

## 완료 조건

- 화면 전체의 톤이 통일되고 쿼카 안내자가 실제 화면에서 확인된다.
- 좁은 화면에서 가로 넘침 없이 입력과 결과를 사용할 수 있다.

## 검증 결과 · 2026-09-23

새 쿼카 자산의 실제 화면 표시를 확인했다. 375×812 세로와 812×375 가로 화면에서 가로 넘침이 없었고, 이미지 HTTP 200 및 브라우저 오류 없음도 확인했다.
