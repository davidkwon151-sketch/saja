# 010 · 반응형 쿼카 안내자 애니메이션

## 목적

참가자가 제공한 로컬 쿼카 페이지(`http://127.0.0.1:8765/`)의 반응형 애니메이션을 커리어 나침반 첫 화면에 적용한다.

## 동작

1. 기존 첫 화면의 정적 쿼카를 원본 페이지의 기본·웃는 쿼카 이미지 두 장으로 교체한다. 원본 파일과 기존 프로젝트 이미지는 보존한다.
2. 쿼카가 천천히 떠 있는 움직임을 보이고, 마우스·펜을 올리거나 버튼을 누르면 웃는 이미지와 짧은 반응 문구를 보여준다. 클릭·터치·키보드 활성화에는 짧은 흔들림과 반짝임도 더한다.
3. 1.8초 뒤 클릭 반응은 끝나고 대기 상태로 돌아간다. 반복 클릭도 정상 동작한다. 한국어·영어 UI에 맞춘 문구를 사용한다.
4. 움직임 줄이기 설정을 존중하고, 버튼 이름·키보드 초점·상태 알림을 제공한다. 모바일 세로·가로 화면에서 가로 넘침 없이 입력 영역과 함께 볼 수 있다.

## 완료 조건

- 원본처럼 대기·웃음 상태가 실제 화면에서 구분된다.
- 클릭, 키보드, 언어 전환, 움직임 줄이기, 작은 화면에서 동작한다.
- 기존 커리어 입력·결과·저장 기능과 빌드가 유지된다.

## 검증 결과 · 2026-09-23

- 원본 로컬 페이지의 기본·웃음 상태와 이미지 파일을 확인해 프로젝트에 복사했다. 원본 파일은 보존했다.
- 실제 브라우저에서 클릭과 Enter 키로 웃는 표정, 말풍선, 상태 문구와 반짝임을 확인했다. 한국어·영어 전환도 확인했다.
- 375×812, 812×375 화면에서 쿼카 이미지가 보이고 가로 넘침이 없음을 확인했다. 두 이미지와 첫 화면의 HTTP 200, 브라우저 오류 없음도 확인했다.
- 독립 테스트 보강 후 `npm run check` 44개 통과, `npm run build` 성공. 움직임 줄이기는 CSS와 테스트에서 확인했고 실제 기기 설정 전환·손가락 터치는 별도로 실행하지 않았다.
