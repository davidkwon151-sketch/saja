# 002 · 취업·이직 고민과 연결하는 사주 해석

## 목적

현재의 년·월·일주 표시 아래에, 사용자가 적은 취업·이직 고민과 연결된 읽기 쉬운 사주 해석을 보여준다. 사주는 자기 성찰의 참고 자료로 다루며 입사 시기나 합격을 예언하지 않는다.

## 동작

1. 출생시간 없이 계산한 년·월·일주와 일간, 고민·희망 직무·현재 상태를 Gemini에 전달한다. 생년월일 원문은 보내지 않는다.
2. AI가 한 문단 요약, 살펴볼 강점 2개, 주의해 볼 점 2개, 스스로 점검할 질문 1개를 작성한다. 기존 3단계 행동 계획과 한 번의 호출로 생성한다.
3. 받은 구조를 검사해 빠진 항목이나 과도하게 긴 응답은 사용하지 않는다. 생성 실패 시 해석 실패를 알려주고 기본 행동 계획은 계속 표시한다.
4. 화면에 AI가 쓴 참고 해석임을 표시하고, 출생시간이 없어 시주와 정확한 경계 판정은 제공하지 않는다는 기존 안내를 유지한다.

## 완료 조건

- 입력 후 사주 해석이 행동 계획 앞에 나타난다.
- 해석은 사용자의 고민과 직무에 연결되며, 합격·시기를 확정하지 않는다.
- 잘못된 AI 응답은 결과로 표시되지 않는다.
- 인증값이 없거나 호출에 실패해도 기본 행동 계획과 공고 화면을 사용할 수 있다.
- 기존 사주 계산·계획·공고 기능이 계속 동작한다.

## 검증

- 해석 응답 구조의 정상·누락 사례 테스트
- 타입 검사, 기존 테스트, 빌드
- 가상 사용자 입력으로 실제 브라우저에서 해석·행동 계획·공고 순서 확인

## 실행 결과 (2026-09-23)

- `npm run check`: 타입 검사와 테스트 23개 모두 통과. 정상 응답, 누락·깨진 JSON, 길이 초과를 검사했다.
- `npm run build`: 성공. `git diff --check`: 문제 없음.
- 가상 데이터로 실제 API를 호출해 해석 1개, 강점·주의점 각각 2개, 계획 3단계와 공고 1개를 받았다. 브라우저에서도 해석 → 행동 계획 → 공고 순서와 콘솔 오류 없음을 확인했다.
- 375×812 및 812×375 화면에서 문서 가로 넘침이 없음을 확인했다. 임시 서버에 잘못된 인증값을 넣어 API의 `reading=null`, 기본 계획 3단계, 공고 응답 유지를 확인했다. 이 실패 상태의 브라우저 화면은 별도 재현하지 않았다.
