# 009 · 고민별 출처 있는 격언

## 목적

취업·이직 고민과 나이에 맞는 짧은 격언을 결과 마지막에 보여주되, 출처 없는 유명인 인용을 만들지 않는다.

## 동작

1. 공개된 국내외 속담·격언 사이트에서 짧은 문구와 원문 주소를 읽어 소규모로 수집한다. 출처와 사용 원칙을 문서로 남긴다.
2. 고민의 주제(시작, 역량 쌓기, 전환, 협업, 실패 회복)와 나이·현재 상태를 이용해 영문 격언 한 개를 고른다.
   선택한 격언 아래에는 희망 직무와 고민 주제를 연결한 짧은 실천 문장을 선택 언어로 표시한다.
3. 출처 있는 문구는 링크와 일반적인 출처 표기를 함께 표시한다. 맞는 문구가 없으면 자체 작성한 기본 문구를 사용한다.
4. 특정인의 발언이라는 근거가 없는 문구는 특정인에게 돌리지 않는다. 긴 본문이나 페이지 배열을 복제하지 않는다.

## 완료 조건

- 고민/연령/언어가 다른 입력에 해당하는 짧은 문구가 나온다.
- AI 호출이 실패해도 결과 마지막에 문구가 나타난다.
- 원문 주소가 문서와 화면에서 확인 가능하다.

## 검증 결과 · 2026-09-23

영문 속담 5개의 원문 페이지 수록을 확인했다. 자동 검사에서 고민별 선택과 AI 실패 시 표시를 확인했으며, 실제 브라우저에서 영어 격언 한 개·한국어 연결 문장·출처 링크를 확인했다.
