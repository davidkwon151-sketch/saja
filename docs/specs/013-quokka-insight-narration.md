# 013 · 쿼카가 들려주는 나의 가능성

## 목적

MY INSIGHTS를 쿼카 이미지와 말풍선 중심의 카드로 바꾸고 저장된 나의 가능성을 음성과 한 글자씩 나타나는 자막으로 전달한다.

## 동작

- 기존 쿼카 이미지 두 장으로 말하는 표정과 움직임을 만든다. 저장된 인사이트를 선택할 수 있다.
- 듣기 버튼을 직접 눌렀을 때 기기 음성으로 요약·강점·성장 조언·질문을 읽는다. 기본 음성 기능이 없는 브라우저에서는 Google AI로 음성을 생성해 재생한다. 자동으로 소리를 내지 않는다.
- 자막이 한 글자씩 나타나고 정지·다시 듣기를 제공한다. 음성 완료 시 전체 글이 보인다.
- 기록 변경·언어 변경·로그아웃·화면 종료 시 음성과 타이머를 정리한다.
- 한국어·영어 조작 문구를 제공하며 저장된 글의 언어를 우선해 읽는다.
- 음성 미지원/실패를 알려주고 텍스트로 계속 확인할 수 있다. 전체 원문을 별도로 읽을 수 있으며 움직임 줄이기 설정에서는 애니메이션을 줄인다.

## 구현 범위와 제한

기존 저장 내용과 데이터베이스 구조를 유지한다. 기기의 SpeechSynthesis와 서버의 Gemini 2.5 Flash Preview TTS를 사용하므로 음색은 기기에 따라 다르다. 서버 음성 생성 시 선택한 인사이트 원문이 Google AI로 전달됨을 화면에 안내한다. API 키는 서버에만 두고 오디오는 저장하지 않으며 no-store 응답을 사용한다. 최대 4,000자, 60초 생성 제한을 둔다.

말하는 움직임은 표정·몸짓 애니메이션이며 음소별 입 모양 합성은 포함하지 않는다. 서버 오디오 자막은 재생 시간 비율을 이용하므로 단어별 정밀한 동기화와는 차이가 있다. 음성 생성 실패 시 오류와 다시 듣기를 제공하고 원문을 계속 볼 수 있다. 생성된 오디오는 해당 카드에 머무르는 동안 다시 듣기에 재사용한다.

참고: [Google 음성 생성 안내](https://ai.google.dev/gemini-api/docs/speech-generation), [브라우저 음성 API](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance).

## 검증

- 독립 테스트: 원문 보존·표시 언어·기록 선택·빈 화면·음성 API 입력/실패/PCM→WAV 검사를 추가했고 전체 57개 통과.
- 빌드 PASS. 실제 한국어 음성 생성 요청 HTTP 200, audio/wav의 RIFF 헤더와 음성 바이트 반환 확인.
- 실제 브라우저에서 저장된 기록 조회, 듣기 시작 이벤트와 말하는 표정·타이핑, 중단, 다른 기록 선택 시 정리, 영어 조작 문구 확인. 원래 저장 데이터에는 쓰기 시험을 하지 않았다.
- 375×812와 812×375에서 가로 넘침 없음, 쿼카 이미지·선택기·버튼 확인, 콘솔 오류 없음.
- 브라우저의 기본 음성 재생 경로를 확인했으며 서버 생성 오디오의 자동 대체 재생 경로는 API 검사로 확인했다. 기기별 실제 음색과 모든 브라우저의 재생 정책은 달라질 수 있다.
