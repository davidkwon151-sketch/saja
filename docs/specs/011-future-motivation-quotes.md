# 011 · 마지막 이미지의 커리어 명언과 격언

## 목적

결과 마지막 이미지에서 나이 네 항목을 없애고, 오늘의 선택이 내일의 커리어를 만든다는 메시지를 전한다.

## 동작

1. 이미지 안에 `내일의 나는 오늘의 내가 만듭니다`를 중심 문구로 표시한다. 영어 화면에는 자연스러운 영어 번역을 사용한다.
2. 네 개의 나이표와 마지막 이미지의 나이 안내 문장은 표시하지 않는다.
3. 고민의 주제에 맞는 짧은 영문 명언 한 개와 영문 격언 한 개를 함께 보여준다. 구직·이직의 시작, 역량 축적, 거절 후 재도전, 협업, 전환에 연결한다.
4. 명언·격언의 저자 또는 종류와 확인 가능한 원문 링크를 붙인다. 각 문구는 검증된 짧은 발췌만 사용한다.
5. AI 사용 불가 시에도 두 문구가 보이고 한국어·영어 화면에서 연결 문장이 선택 언어로 보인다.

## 완료 조건

- 결과 마지막 이미지에 정확한 메시지와 명언·격언이 보이며 나이표 네 개가 없다.
- 서로 다른 고민에 알맞은 문구가 선택되고 출처 링크가 열린다.
- 기존 결과와 언어 전환, 작은 화면 표시가 동작한다.
