# 012 · 날짜 입력 빠르게 선택하기

## 목적

생년월일을 선택할 때 달력을 여러 해 넘기는 불편함과 입사 목표일을 일일이 찾는 부담을 줄인다.

## 동작

1. 양력 생년월일을 연도 숫자, 월, 일로 바로 입력한다. 해당 월에 존재하는 날짜만 표시하고 출생시간은 받지 않는다.
2. 입사 목표일은 3개월·6개월·1년 뒤를 한 번에 선택할 수 있다. 날짜 입력란에서 원하는 날로 직접 바꿀 수도 있다.
3. 기존 API에는 `YYYY-MM-DD` 형식의 `birthDate`, `targetDate`를 그대로 전송한다. 서버의 날짜 검증과 결과 생성은 유지한다.
4. 한국어·영어 문구, 키보드, 모바일 화면을 지원한다.

## 완료 조건

- 두 날짜를 빠르게 입력하거나 직접 조정할 수 있다.
- 잘못된 생년월일과 지난 목표일은 결과 생성 전에 차단한다.
- 기존 결과 생성 및 저장 흐름과 한국어·영어 화면이 유지된다.

## 검증 결과

- 독립 테스트 에이전트가 연·월·일 필드, 한국어·영어 문구, 세 가지 목표일 빠른 선택, 목표일의 최소 날짜를 검증했다.
- `npm run check` 타입 검사와 전체 테스트 48개가 통과했다.
- 실제 브라우저에서 2000-02-29와 3개월 뒤 목표일을 선택해 결과 생성까지 확인했다. 375×812·812×375 화면에서 가로 넘침 없이 입력을 읽고 누를 수 있었다. `npm run build`도 통과했다.
