# 005 · 현대적인 커리어 사주 해석

## 목적

부족한 실제 공고 목록을 제거하고, 취준생과 이직 준비자가 자신의 잠재력을 취업 행동에 연결할 수 있는 짧고 힘이 되는 해석을 제공한다.

## 동작

1. `LIVE OPPORTUNITIES` 화면과 Remotive 조회를 제거한다. 모집 공고를 가져오거나 API 응답에 넣지 않는다. 3단계 행동 계획에는 지원·교육·프로젝트 등의 활동 제안을 유지한다.
2. 사주 계산은 유지하되 AI 해석에는 어려운 명리학 용어·한자·운명 단정 대신 현대적인 한글 중심 문장과 필요한 경우 쉬운 영문 커리어 표현을 쓴다.
3. 요약에는 해석에서 본 잠재력과 희망 직무나 현재 고민에 적용할 방법을 연결한다. 격언은 `006-personal-future-ending.md`에 따라 결과 마지막에 별도로 표시한다. 출처가 확인되지 않은 유명인 발언을 인용하거나 합격·적성을 보장하지 않는다.
4. 강점 2개는 실제 취업·이직 과정에서 활용할 행동으로, 점검할 점 2개는 성장 가능한 실천 조언으로, 마지막 질문은 지금 시작할 작은 도전으로 작성한다. 간결하고 격려하는 어조를 사용한다.
5. 새로 생성한 해석의 한자 표기를 정리한 뒤 저장한다. 이미 데이터베이스에 저장된 해석도 `MY INSIGHTS` 목록 제목과 본문에서 한자와 낡은 명칭이 보이지 않도록 표시한다. 기존 저장 원본은 삭제하거나 수정하지 않는다.

## 완료 조건과 검증

- 결과 화면에 `LIVE OPPORTUNITIES`, 공고 목록, 공고 조회 안내가 없다. 해석과 행동 계획은 계속 표시된다.
- 새 해석과 저장된 옛 해석의 표시 문구에 한자가 없다. 괄호 속 한자만 있던 흔적도 남지 않는다.
- 해석 생성 지시문이 잠재력, 취업·이직 활용, 과장 없는 응원을 요구한다. 격언은 확인된 출처에서 별도로 고른다.
- 자동 검사, 빌드, 실제 브라우저에서 생성 결과와 기존 입력 흐름을 확인한다.

## 검증 결과 · 2026-09-23

자동 검사 39개 통과, 빌드 성공. 실제 Gemini 요청에서 현대적인 해석과 3단계 계획을 확인했고, 브라우저의 기존 저장 기록에서 옛 명칭과 한자가 화면에 보이지 않음을 확인했다.
