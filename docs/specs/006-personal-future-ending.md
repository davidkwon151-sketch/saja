# 006 · 나이에 맞춘 미래 장면과 격언

## 목적

결과의 마지막에 사용자가 준 이미지의 메시지를 바탕으로, 인생과 커리어는 정해진 것이 아니라 지금의 선택과 행동으로 만들어 간다는 희망을 전한다.

## 동작

1. 제공된 이미지는 글자와 고정 나이 표시를 제거한 새 프로젝트 이미지로 보존한다. 사용자마다 달라지는 문구와 나이는 이미지 위의 웹 텍스트로 표시한다.
2. 입력 생년월일에서 한국 날짜 기준 만 나이를 계산한다. 이미지 위 인물 4명의 나이는 사용자 나이를 중심으로 앞뒤 7살 이내에서 표시한다. 나이 정보를 데이터베이스에 저장하지 않는다.
3. 결과 마지막에 `내 고민과 연결한 격언` 제목과 영문 격언 한 개를 항상 표시한다. 공개된 속담 자료에서 출처를 확인한 짧은 격언을 사용자의 나이·취업 또는 이직 고민·희망 직무에 맞춰 고른다. AI 실패나 적절한 격언이 없는 경우에도 자체 작성한 영문 기본 문구를 표시한다.
4. 격언 아래에는 선택한 화면 언어로 고민과 연결한 실천 문장을 표시한다. 특정 인물의 말을 출처 없이 인용하지 않는다. 취업 성공·입사 시기·운명을 보장하지 않고 당장 시도할 행동을 북돋는다. 이미지 위의 나이표에는 숫자만 표시한다.
5. 이 장면은 행동 계획과 저장된 해석 목록 뒤, 결과의 마지막에 놓는다. 입력 오류로 결과가 없을 때는 표시하지 않는다. 좁은 화면에서도 글자가 읽히고 나이표가 이미지 안에서 보인다.

## 완료 조건과 검증

- 20대·40대 등 다른 생년월일에서도 이미지 위 네 나이가 각각 사용자 만 나이 ±7 범위다.
- 격언은 정확한 제목 아래 항상 나타나며 사용자 고민과 나이를 반영한다. AI 호출 실패에도 격언이 나온다.
- 새 이미지가 존재하고 화면에서 로드된다. 한자·기존 나이와 겹치는 이미지 글자는 없다.
- 기존 사주 해석·3단계 계획·Google 로그인·저장 동작을 해치지 않는다.

## 검증 결과 · 2026-09-23

자동 검사에서 연령 ±7 범위와 결과 마지막 위치를 확인했다. 비회원 가상 입력의 실제 브라우저 결과에 영문 격언 한 개와 나이 숫자 4개가 보였고, 네 설명 문구는 표시되지 않았다. 이미지 HTTP 200을 확인했다.
